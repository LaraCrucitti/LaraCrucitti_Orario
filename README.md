Crucitti Lara 3AII

Questo progetto serve a simulare un orologio attraverso la classe COrario il programma (teoricamente) può mostrare un orario tenendo conto del massimo di secondi e minuti, aggiungere secondi minuti o ore, confrontare due orari.



Funzionalità implementate 

costruttore di default se non vengono inseriti i valori in input 

funzione Normalizza() che sistema l'orario se i secondi o i minuti superano 59

funzione ToString() per scrivere il messaggio così 00:00:00

funzione ToSecondi() trasforma l'orario in secondi 

funzione Aggiungi(int secondi ) che aggiunge secondi all'orario 

funzione Aggiungi(int ore,int minuti, int secondi) aggiunge ore, minuti e secondi 

Confronta(COrario a, COrario b) che confronta due orari restituendo il maggiore
